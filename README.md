# Study Break Coach

Study Break Coach is a simple Flutter app that suggests a short break activity based on how much time a student has and how focused they feel.

## Sample

The current sample demonstrates a single screen with:

- A time available selector
- A focus level selector
- A button that suggests a break
- A card that displays the suggestion

## Built with

- Flutter
- Dart

The app works offline and does not use a database.

## Planned project

The finished project will expand the sample with a polished interface and a wider range of useful break suggestions.
